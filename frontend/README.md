# E:Revive

React + Vite frontend and Spring Boot backend for **E:Revive – A Smart E-Waste Management System**.

## Requirements

- Node.js 18 or later
- Java 17 or later
- Apache Maven 3.6.3 or later

## Run in VS Code or IntelliJ IDEA

Open the project root (the folder containing this README) and use two terminals.

### Spring Boot backend

```powershell
cd backend
mvn.cmd spring-boot:run
```

The API starts at `http://localhost:8080`. Its H2 database is stored in `backend/data/erevive.mv.db`; accounts, assessments, uploaded images, and pickup bookings persist across restarts.

In IntelliJ IDEA, open `backend/pom.xml` as a Maven project and run `mvn spring-boot:run` from the backend terminal (or run `com.erevive.EReviveApplication`).

### React frontend

From the project root:

```powershell
npm.cmd install
npm.cmd run dev
```

Open `http://localhost:5173`. The frontend calls `http://localhost:8080/api` directly; Spring Boot CORS allows both `localhost:5173` and `127.0.0.1:5173`. To use another API base URL, copy `.env.example` to `.env` and set `VITE_API_URL`; restart Vite after changing it. The Vite `/api` proxy is also available by setting `VITE_API_URL=/api`.

## API routes

| Method | Route | Purpose |
|---|---|---|
| GET | `/api/health` | Backend health check |
| POST | `/api/auth/register`, `/api/auth/login` | Create an account and start a session |
| POST | `/api/survey` | Submit questionnaire answers and an optional image (`multipart/form-data`) |
| GET | `/api/analyses/{id}` | Retrieve a saved assessment and estimate |
| GET | `/api/analyses/{id}/image` | Retrieve the image saved with an assessment |
| POST | `/api/pickups` | Save a pickup booking linked to an assessment |
| GET | `/api/dashboard` | Retrieve persisted assessments, pickups, and totals |

If the backend is unavailable, the frontend shows a connection error and does not create local substitute records or decisions. Password-reset emails require a mail service and are not configured by default.

The backend currently makes reuse/recycle decisions with server-side questionnaire scoring and produces indicative category-based value and environmental estimates. This project did not include a trained ML model artifact, so these results are not generated by an ML inference model.

On Windows PowerShell, use the `.cmd` command names above to avoid PowerShell script execution-policy issues. If Node.js or Maven was just installed, reopen VS Code or open a new terminal so the updated user `PATH` is loaded.
